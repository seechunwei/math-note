
Important properties of linear systems can be described with the concept and notation of vectors.

Vectors in $\mathbb{R}^{2}$
A matrix with only one column is called a column vector or simply a vector.

The set of all vectors with two entries is denoted by $\mathbb{R}^{2}$. The $\mathbb{R}$ stand for real number as entries and the exponent indicate how many entries.

The vector is an order pair if it has 2 entries. It act like n-tuple. 

The sum obtained by adding corresponding entries

and scalar multiple $c$ obtained by multiplying each entry by $c$.

### Linear Combination

Given vectors $v_{1},\dots,v_{n}$ in $\mathbb{R}^{n}$ and given scalars $c_{1},\dots c_{n}$, , the vector $y$ defined by
$$
y=c_{1}v_{1}+c_{2}v_{2}+\dots+c_{n}v_{n}
$$
is called a linear combination of $v_{1},\dots,v_{n}$ with weights $c_{1},\dots,c_{n}$.

Suppose 2 vectors $v_{1}=\bigl( \begin{smallmatrix} -1\\1\end{smallmatrix} \bigr)$ and $v_{2}=\bigl( \begin{smallmatrix} 2\\1\end{smallmatrix} \bigr)$.
The linear combination of produce a parallel grids lines.

A vector equation
$$
x_{1}a_{1}+x_{2}a_{1}+\dots+x_{n}a_{n}=b
$$

has the same solution set as the linear system whose augmented matrix is

$$
\begin{bmatrix}
a_{1} & a_{2} & \dots & a_{n} & b
\end{bmatrix}
$$
In particular, b can be generated by a linear combination of $a_{1},\dots a_{n}$ if and only if there exists a solution to the linear system corresponding to the matrix

Checking if a vector $b$ is in $Span\{ v_{1},\dots,v_{n} \}$ is equivalent  to asking whether the augmented matrix
$$
\begin{bmatrix}

\end{bmatrix}

==Theorem 3==
If $A$ is an $m\times n$ matrix with column $a_{1},\dots,a_{n}$, and $b$ is in $\mathbb{R}^{m}$,

$$
Ax=b
$$
has the same solution set as the linear combination of column of $A$
$$
x_{1}a_{1}+\dots x_{n}a_{n}=b
$$
and has the same solution as the augmented matrix

$$
\begin{bmatrix}
a_{1} & \dots & a_{n} & b
\end{bmatrix}
$$

### A Geometric Description of Span$\{ v \}$ and Span$u,v$

Suppose $v$ is a nonzero vector in $\mathbb{R}^{3}$. Then , the $Span\{ v \}$ is the set of all point on a line passing though the origin and $v$.

If $u,v$ are nonzero vectors in $\mathbb{R}^{3}$. With the assumption that $u$ is not multiple of $u$, the $Span\{ u,v \}$ is the set of all point in a plane contain origin,  $u$ and $v$

==Remark==
To locate a point in $\mathbb{R}^{3}$ we need 3 coordinate corresponding to each entry of vector. Since vector is an arrow from origin, thus the $Span\{ v \}$ form a line.

If we have 2 vectors, then we have 2 point with origin we can form a plane.
