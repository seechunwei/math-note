[[4.4 Coordinate System#^632885]]

**1. Define a starting point in the original parallelogram**

Let $p$ be an arbitrary point in the parallelogram $P$ determined by the vectors $u$ and $v$.

By the definition given in your problem, we can write $p$ as a linear combination of $u$ and $v$:

$$p = au + bv$$

where the scalars $a$ and $b$ are restricted to the ranges $0 \le a \le 1$ and $0 \le b \le 1$.

**2. Apply the linear transformation**

Now, we want to find the image of this point $p$ under the transformation $T$. We plug $p$ into our function:

$$T(p) = T(au + bv)$$

**3. Use the properties of linear transformations**

By definition, a transformation $T$ is **linear** if and only if it satisfies two core properties:

- **Additivity:** $T(x + y) = T(x) + T(y)$
    
- **Scalar Multiplication:** $T(cx) = cT(x)$
    

We can apply these properties to our equation. First, using additivity, we can split the vector addition:

$$T(au + bv) = T(au) + T(bv)$$

Next, using the scalar multiplication property, we can pull the scalars $a$ and $b$ out to the front:

$$T(au) + T(bv) = aT(u) + bT(v)$$

**4. Analyze the result**

We have just shown that:

$$T(p) = aT(u) + bT(v)$$

Notice that the scalars $a$ and $b$ haven't changed. They are the exact same numbers we started with, meaning the original constraints still apply:

- $0 \le a \le 1$
    
- $0 \le b \le 1$
