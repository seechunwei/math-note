What is onto function?
Suppose f is a function denoted $f:X\to Y$. We say f is onto iff for all element in Y, there exists an element in X such that $y=f(x)$

The onto function restrict the function so that we need to take every element in codomain which is $Y$ that will map to some $x \in X$ under certain function. It means that the $rng(f)=cod(f)$.

To show that a function f is onto, we first suppose y is an arbitrary element in the codomain of f . Then we show that there exists an element x in the domain of f such that f(x) = y.

Notice that the corresponding element in X is defined in term of y. And we need to show that the x is in the $dom(f)$.

And show that $f(x)=y$

Whether a function is onto sometimes depend greatly on the domain and codomain. For example
$f: X\to Y$
$f(x)=x^{3}$ for all $x \in X$

if $X=\mathbb{R}$ and $Y=\mathbb{R}$. It is true we take $x=^{3}\sqrt{ y }$ 
if $X=\mathbb{R}^{+}$ and $Y=\mathbb{R}$ it is wrong because that does not exist a element $x \in X$ that map to negative value y
