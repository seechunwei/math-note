==Theorem 4==
 **The Matrix Spanning Theorem**
Let $A$ be an $m \times n$ matrix. The following four statements are **logically equivalent**—meaning for any given matrix, they are either all true or all false: ^b8d6b7

- **a. Universal Solvability:** For every vector $\mathbf{b}$ in $\mathbb{R}^m$, the equation $A\mathbf{x} = \mathbf{b}$ has at least one solution.
    
- **b. Column Combinations:** Every vector $\mathbf{b}$ in $\mathbb{R}^m$ can be expressed as a linear combination of the columns of $A$.
    
- **c. Spanning Power:** The columns of $A$ span the entire vector space $\mathbb{R}^m$.
    
- **d. Pivot Sufficiency:** The matrix $A$ contains a pivot position in every one of its $m$ rows.

$a,b,c$ is equivalent obviously , they are just different way to view the same thing, and $a$,d is equivalent with a proof.

Prove c,d:
Suppose $A$ is a $m\times n$ matrix where the columns of $A$ span the entire vector space $\mathbb{R}^{m}$. Then, it follow that $A$ has at least $m$ linearly independent column vectors. Thus, it follow that $ref(A)$ has at least $m$ pivot, since the number of pivot is at most min(m,n), it follow that $m\leq n$. Thus, $ref(A)$ has $m$ pivot and it appear in every row. Notice iff $m=n$, then $A$ is a square matrix and it follow that $A$ has pivot in every columns, thus it has unique solution for each $b \in \mathbb{R}^{m}$

Prove a,d:
Suppose for every vector $\mathbf{b}$ in $\mathbb{R}^m$, the equation $A\mathbf{x} = \mathbf{b}$ has at least one solution. Then, it must have pivot in every row. [[1.2 Row Reduction and Echelon Forms#^ed52d1]]

## 1. The Trivial Solution Requirement

If a matrix $A$ is **invertible**, the homogeneous equation $Ax = 0$ has **exactly one solution**: the trivial solution ($x = 0$). We can prove this by multiplying by the inverse:

$$A^{-1}(Ax) = A^{-1}(0)$$

$$(A^{-1}A)x = 0$$

$$Ix = 0 \implies x = 0$$

For a system to have _only_ the trivial solution, every single column in the matrix must be a **pivot column**. If even one column lacked a pivot, we would have a "free variable," which would lead to infinitely many solutions.
