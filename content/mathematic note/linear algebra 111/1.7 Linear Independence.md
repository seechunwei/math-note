
==Definition==
An indexed set of vector $\{ v_{1},\dots,v_{p} \}$ in $\mathbb{R}^{n}$ is said to be linearly independent if the vector equation

$$
x_{1}v_{1}+x_{2}v_{2}+\dots x_{p}v_{p}=0
$$

has only trivial solution. The set is said to be linearly dependent if there exist $c_{1},\dots,c_{p}$ not all zero, such that
$$
c_{1}v_{1}+c_{2}v_{2}+\dots c_{p}v_{p}=0
$$

Equation (2) is called a linear dependence relation among $v_{1},\dots,v_{p}$. Notice that linearly independent and linearly dependent is negation of each other. (all zero, not all zero)

Notice that linear dependency is determine by the dimension of nullspace, a set of vector is linear dependent iff the nullspace form by matrix $A$ (The column of $A$ is the set of vectors) is not a zero vector.

==Theorem 7==
An indexed set $S=\{ v_{1},\dots,v_{p} \}$ of two or more vectors is linearly dependent iff at least one of the vectors in $S$ is a linear combination of the others. In fact, if $S$ is linearly dependent and $v_{1} \neq 0$, then some $v_{j}$ (with $j>1$) is a linear combination of the preceding vectors, $v_{1},\dots,v_{j-1}$

Proof:
An indexed set $S=\{ v_{1},\dots,v_{p} \}$ of two or more vectors is linearly dependent and $v_{1} \neq{0}$. Then by definition,

There exist some non zero scalar $c_{1},\dots,c_{p}$ such that

$$
c_{1}v_{1}+c_{2}v_{2}+\dots+c_{n}v_{n}=0
$$
Let $i$ be the largest subscript for which $c_{i} \neq 0$ where $i \in \{ 2,\dots,n \}$. $i\neq 1$, because this contradict our assumption $v_{1} \neq 0$.

> [!cite] Remark
> Why suppose $j$ is the largest subscript? Try think of the theorem, there exist a $v_{j}\in Span\{ v_{1},\dots,v_{j-1} \}$ , in the set $\{ v_{1},\dots,v_{j-1},v_{j} \}$, $v_{j}$ is the vector with largest subscript. In other word, the must be a vector with largest subscript that satisfy this theorem.
>  We need to show that
$$c_j v_j = -c_1 v_1 - c_2 v_2 - \dots - c_{j-1} v_{j-1}$$

Because $j$ is the largest index with a non-zero coefficient, every coefficient after $j$ is zero ($c_{j+1} = \dots = c_n = 0$). Thus,

$$
-c_{j}v_{j}=c_{1}v_{1}+\dots c_{j-1}v_{j-1}
$$
Dividing both sides by $-c_j$ yields:

$$v_j = \left(-\frac{c_1}{c_j}\right)v_1 + \left(-\frac{c_2}{c_j}\right)v_2 + \dots + \left(-\frac{c_{j-1}}{c_j}\right)v_{j-1}$$

Thus, $v_{j}\in Span \{ v_{1},\dots,v_{j-1} \}$

Suppose there exists some index $j > 1$ such that $v_j$ is a linear combination of $v_1, \dots, v_{j-1}$.

Thus, 

$$
c_{j}=a_{1}v_{1}+\dots a_{j-1}v_{j-1}
$$
for some scalar $a_{1},\dots,a_{j-1}$. Thus,

$$
a_{1}v_{1}+\dots+a_{j-1}v_{j-1}-1c_{j}=0
$$

To make this an equation for the _entire_ set $S = \{v_1, \dots, v_n\}$, we can simply assign a coefficient of $0$ to all remaining vectors that follow $v_j$:

$$a_1 v_1 + a_2 v_2 + \dots + a_{j-1} v_{j-1} - 1v_j + 0v_{j+1} + \dots + 0v_n = 0$$

There exist a non zero scalar which is $-1$ which implies that $S$ is linearly dependent.
