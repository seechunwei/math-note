==Definition==
The column space of a matrix $A$ is the set $Col(A)$ of all linear combinations of the columns of $A$.

==Definition==
The null space of a matrix $A$ is the set $Nul(A)$ of all solutions of the homogeneous equation $Ax=0$.


The solution set of $Ax=0$ form a basis for $Nul (A)$. Why? ^6c5471

Suppose $A$ is a $m\times n$ matrix. Thus, $Nul(A)\in \mathbb{R}^{n}$.

$Nul(A)$ is actually $Span\{ v_{1},\dots,v_{k} \}$ where $k$ is the number of free variable. The nullity determine the dimension of $Nul(A)$.

Thus, the parametric vector form of the solution set for $Ax=0$ is

$$
x_{1}v_{1}+\dots x_{k}v_{k}
$$
where $x_{1},\dots x_{k}$ are free variable. $Nul(A)$ is all the solution set $x$ for $Ax=0$.

If we were to look at the actual entries of the vectors, we would see a very specific pattern:

Since $x_{1}$ is free variable, it follow that the first entry of $v_{1}$ is 1 and $i-th$ entry is all zero for $i \in \{ 1,\dots,k \}-\{ 1 \}$. (we get the first vector by setting other free variable equal to 0)

and it is the same to up to $x_{k}v_{k}$. Thus, the system below only has trivial solution.

$$
x_{1}v_{1}+\dots x_{k}v_{k}=0
$$

For the first entry to be zero, $x_{1}$ must equal to 0 because the first entry of $v_{1}$ is 1 while other vector is 0. Thus, it is clear that the vector set that span the $Nul(A)$ are linearly independent. Thus, it form a basis of $Nul(A)$.

### Lecture Note

The difference between linear combination and span?

1) A linear combination of vectors $v_{1},v_{2},\dots,v_{p}$  is the vector

$$
c_{1}v_{1}+c_{2}v_{2}+\dots+c_{p}v_{p}
$$
where $c_{1},c_{2},\dots,c_{p}$ are scalars. 

2) A set that consists of all linear combination of $v_{1},\dots,v_{n}$ is called the linear span of $v_{1},\dots,v_{n}$:

$$
Span\{ v_{1},\dots,v_{n} \}=\{ c_{1}v_{1}+\dots c_{n}v_{n}:c_{1},\dots,c_{n \in \mathbb{R}} \}
$$

==Remark==
(A linear combination is a single path to reach the destination) 
The correspond question is iff $v$ can be express as a linear combination a vector set.

(A linear span is the map in the vector space)
The correspond question is if the vector set span the vector space.

For both question we need to find the solution for

$$
\begin{bmatrix}
v_{1} & v_{2} & \dots & v_{n}
\end{bmatrix}\begin{bmatrix}
c_{1} \\
\vdots  \\
c_{n}
\end{bmatrix}=v
$$
One is general, one is particular.

==Definition==
Let $S=\{ v_{1},\dots,v_{n} \}$ be a subset of a vector space $V$ over $\mathbb{R}$. Then $S$ is called a generating set (or spanning set) of a subset $W$ of $V$ if every vector in $W$ can be written as a linear combination of $S$:

$$
W=Span\{ v_{1},\dots,v_{n} \}=\left\{  \sum_{i=1}^{n} c_{i}v_{i}:c_{i }\in \mathbb{R}  \right\}
$$

The set $S$ is also said to span $W$.

==Definition==
Let $S$ be nonempty subset of a vector space $V$. Then the set

$$
Span(S)=\left\{  \sum_{i=1}^{n} c_{i}v_{i}:v_{i} \in S,c_{i} \in \mathbb{R}  \right\}
$$

> [!info]
> For empty set $\emptyset$. we define $Span\{ \emptyset \}=\{ 0 \}$

==Theorem==
For $v_{1},v_{2},\dots,v_{n}$ in a vector space $V$  $\mathbb{R}$ (or $\mathbb{C}$), the linear span, $Span\{ v_{1},\dots,v_{n} \}$ is a subspace of $V$. ^5776a2

When we talk about the vector space, we need to define 2 operation which is addition and scalar multiplication.  

The element in a linear span is a linear combination of the vector set. Thus, we need to defined the sum of 2 linear combination. (To show that they can be written as a linear combination)


==Theorem==
Suppose that $V$ is a vector space over $\mathbb{R}$ (or $\mathbb{C}$) and $v_{1},\dots,v_{n}$ are vectors in $V$. Then for $a_{1},\dots,a_{n},b_{1},\dots ,b_{n}$ in $\mathbb{R}$ (or $\mathbb{C}$) and scalar $\alpha$,



$$
\sum_{i=1}^{n} a_{i}v_{i}+\sum_{i=1}^{n}b_{i}v_{i}=\sum_{i=1}^{n} (a_{i}+b_{i})v_{i} 
$$

(Once we show this, automatically the addition is closured).

$$
\alpha \sum_{i=1}^{n} a_{i}v_{i}=\sum_{i=1}^{n} (\alpha a_{i})v_{i}
$$
(Once we show this, automatically the scalar multiplication is closured).


> [!info]
> We can prove by mathematical induction


Now we can prove the theorem above
[[2.8 Subspace#^5776a2]] with these 2 operation.


==Remark==
Note that $Span\{ v_{1},\dots,v_{n} \}$ is the smallest subspace that containing the vectors $v_{1},\dots,v_{n}$.

Let $H$ be any subspace of $V$ containing $v_{1},\dots,v_{n}$. Then, it follow that $c_{1}v_{1}+\dots+c_{n}v_{n}$ for $c_{1},\dots,c_{n}\in \mathbb{R}$ is in $H$. This implies linear span $Span\{ v_{1},\dots,v_{n} \}$ is the subset of $H$.


==Example==
Determine whether the set $\{ 1-x,1+2x,1+8x \}$ spans $P_{1}(\mathbb{R})$ over $\mathbb{R}$. 

the general form of polynomial in $P_{1}(\mathbb{R})$ is $a+bx$. And this can be view as 

$$
\begin{bmatrix}
a \\
b
\end{bmatrix} \in \mathbb{R}^{2}
$$
Why is not row? Because it ask whether it spans $P_{1}(\mathbb{R})$, it is equivalent of asking if it span $\mathbb{R}^{m}$ , thus $m=2$. It ask about the column space and column space concern about the range which is determine by the number of row.

Thus, we are asking if for any $b \in \mathbb{R}^{2}$, there exist a solution set for $Ax=b$ denoted by

$$
\begin{align}
\begin{bmatrix}

-1 & 2 & 8 & b
\end{bmatrix} &\sim \begin{bmatrix}

$$

When we solve the system we get

$$
x_{1}= \frac{1}{3}(2a-b)+2x_{3}
$$
$$

$$
For any real number $x_{3}$.




==Proper way to write==
Let $p_{1}=1-x$ $p_{2}=1+2x$ $p_{3}=1+8x$

$$
\begin{align}
p=a+bx&=c_{1}p_{1}+c_{2}p_{2}+c_{3}p_{3} \\
&=(c_{1}+c_{2}+c_{3})+(8c_{3}+2c_{2}-c_{1})x

Thus,
$$
c_{1}+c_{2}+c_{3}=a
$$
$$
-c_{1}+2c_{2}+8c_{3}=b

Thus,
$p=\left( \frac{1}{3}(2a-b)+2x_{3} \right)p_{1}+(\frac{1}{3}(a+b)-3x_{3})p_{2}+x_{3}p_{3}$

==Remark==
The question is asking about the column space but why got one free variable $x_{3}$ used to express column space?

When a question asks about the **column space** (or whether a set of vectors spans a space), it is asking an existence question. The presence of a free variable does not stop a vector from being in the column space. It just changes _how many ways_ you can get there. (It is not a basis)
