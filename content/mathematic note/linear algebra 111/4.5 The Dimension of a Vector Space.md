Theorem 9 in Section 4.4 implies that a vector space $V$ with a basis $B$ containing $n$ vectors is isomorphic to $\mathbb{R}^{n}$.

The number $n$ is an intrinsic property (called the dimension) of the space $V$. The discussion of it will give additional insight into properties of bases.

Notice that dimension is only for a vector space.

> [!info] Theorem 10
If a vector space $V$ has a basis $B=\{ b_{1},\dots,b_{n} \}$, then any set in $V$ containing more than $n$ vectors must be linearly dependent.

It is the same as this theorem.
[[4.3 Linearly Independent Sets, Bases#^3d1309]]

After we learn the coordinate system imposed by basis, we can prove this easily.

Proof:
Let $\{ u_{1},\dots,u_{p} \}$ be a set in $V$ with more than $n$ vectors. The coordinate vectors $[u_{1}]_{B},\dots[u_{p}]_{B}$ form a linearly dependent set in $\mathbb{R}^{n}$ because there are more vectors $(p)$ than entries $(n)$ in each vector. Since the coordinate mapping is a isomorphism, it preserve the linear dependence relationship. Thus, it follow that $\{ u_{1},\dots,u_{p} \}$ is linearly dependent.
Why?

By definition of linear dependence, there exist scalars $c_{1}, \dots, c_{p}$, not all zero, such that:

$$c_{1}[u_{1}]_{B} + \dots + c_{p}[u_{p}]_{B} = \mathbf{0}$$

Because the coordinate mapping $T: V \to \mathbb{R}^n$ defined by $T(x) = [x]_B$ is a linear transformation (specifically an isomorphism), it preserves linear combinations. We can rewrite the equation as:

$$[c_{1}u_{1} + \dots + c_{p}u_{p}]_{B} = [\mathbf{0}]_{B}$$

Since the coordinate mapping is one-to-one (injective), the only vector that maps to the zero vector is the zero vector itself. Therefore:

$$c_{1}u_{1} + \dots + c_{p}u_{p} = \mathbf{0}$$

Since the scalars $c_{1}, \dots, c_{p}$ are not all zero, it follows that the original set $\{ u_{1}, \dots, u_{p} \}$ is linearly dependent. $\blacksquare$

If a vector space $V$ is spanned by a **finite set**, then $V$ is said to be **finite-dimensional**, and the **dimension** of $V$, written as dim $V$, is the number of vectors in a basis for $V$. > [!info] Theorem 12
Let $H$ be a subspace of a finite-dimensional vector space $V$. Any linearly independent set in $H$ can be expanded, if necessary, to a basis for $H$. Also, $H$ is finite-dimensional and
>
>$$
\text{dim }H\leq \text{dim }V
$$

Proof:
Let $S=\{ u_{1},\dots,u_{p} \}$ be any linearly independent set in $H$. If $Span ~S=H$, then $S$ is the basis of $H$ by definition. If $Span~S \neq H$, then there exist some vector $u_{p+1}\in H$ such that $u_{p+1} \not\in Span\{ u_{1},\dots,u_{p} \}$. Thus, the set $\{ u_{1},\dots,u_{p},u_{p+1} \}$ is linearly independent.

We can continue this process until $S$ span $H$. The dimension of $S$ never exceed the dimension of $H$ (By theorem 10). So eventually, $Span ~S=H$ and hence form a basis of $H$ and $dim~H\leq dim~V$. $\blacksquare$

> [!info] Theorem 13
The Basis Theorem
Let $V$ be a $p-dimensional$ vector space, $p\geq 1$. Any linearly independent set of exactly $p$ elements in $V$ is automatically a basis for $V$. Any set of exactly $p$ element that span $V$ is automatically a basis for $V$.

Proof:
By theorem above any linearly independent set $S$  of $n$ element in $V$ can be extended to a basis for $V$. Since $V$ is a n-dimensional space, and by theorem 11 every basis must have exactly $n$ vectors. So $S$ must already be a basis for $V$.

Now suppose that $S$ has $n$ element and spans $V$. By Spanning Set Theorem implies that subset $S'$ of $S$ is a basis. Since dim $V=p$, $S'$ must contain $n$ element. Thus, $S=S'$. $\blacksquare$

### The Dimensions of Nul A, Col A, and Row A

> [!info] Definition
The rank of an $m\times n$ matrix $A$ is the dimension of the column space and the nullity of $A$ is the dimension of the null space.

We know that the pivot column of $A$ form a basis of Col A and since $ref(A)$ have the same linear dependence relationship with A. Thus, the number of pivots of $ref(A)$ is the rank of $A$. 

Since we know that A and $ref(A)$ have same row space. Thus, the dimension of Nul A can be determine by the number of pivot of $ref(A)$. Thus, rank of $A$ is also equal to Row A.

The nullity is the number of vector of basis for $Nul$ A. Since we know that the explicit description of Nul A by solving $Ax=0$ form a linear span of linearly independent vectors set that span Nul A. Thus, it is the basis for $Nul$ A and the number of vector in the set is the nullity. Notice that the number of vector in that set is determine by the number of free variable.

Thus, The rank of an $m\times n$ matrix $A$ is the number of pivots columns while the nullity of $A$ is the number of free variable. dimension of Row A also equal to the rank of $A$. 

> [!info] The Rank Theorem
The dimensions of the column space and the null space of an $m\times n$ matrix $A$ satisfy the equation
>
>$$
\text{rank }A+ \text{ nullity }A=\text{ number of columns in }A$$

Proof: 
By theorem 6, rank $A$ is the number of pivot columns in $A$. The nullity of $A$ equals the number of free variables in the equation $Ax=0$. In another word, nullity is the number non-pivot columns of $A$. Thus the number of pivot columns plus the number of non-pivot columns is the total number of columns. $\blacksquare$



Remark
In Chapter 6 we will learn Row $A$ and Nul $A$ have only the zero vector in common and are actually perpendicular to each other.

The same fact applies to Row $A^{T}$ (Col $A$) and Nul $A^{T}$. Why it is perpendicular?

Because Nul $A$ is the $x$ where $Ax=0$. Thus,

$$\begin{bmatrix} \text{— } \mathbf{r}_1 \text{ —} \\ \text{— } \mathbf{r}_2 \text{ —} \\ \text{— } \mathbf{r}_3 \text{ —} \end{bmatrix} \begin{bmatrix} | \\ \mathbf{x} \\ | \end{bmatrix} = \begin{bmatrix} 0 \\ 0 \\ 0 \end{bmatrix}$$

his means that the dot product of every single row vector $\mathbf{r}_i$ with $\mathbf{x}$ must equal zero:

$$\mathbf{r}_i \cdot \mathbf{x} = 0$$

It is the same as Col $A$ and Nul $A^{T}$

> [!info] Rank and the Invertible Matrix Theorem
Let $A$ be an $n\times n$ matrix. Then the following statement are each equivalent to the statement that $A$ is an invertible matrix.
>
m. The columns of $A$ form a basis of $\mathbb{R}^{n}$
n. Col $A=\mathbb{R}^{n}$
o. rank $A=n$
p. nullity $A=0$
q. Nul $A=\{ 0 \}$

Proof:
$m$ is logically equivalent to statement (e) and (h) regarding linear independence and spanning. The other five statement are link by the following chain

$$
g\implies n \implies o \implies p \implies q \implies d
$$
Start with $g$ which says that the equation $Ax=b$ has at least one solution for each b in $\mathbb{R}^{n}$. Thus, Col $A=\mathbb{R}^{n}$. thus there are $n$ pivot columns. Hence, rank $A=n$ $\implies p\implies q$. Thus, the equation $Ax=0$ only has the trivial solution (d). $\blacksquare$
