What if the number of data is very large
Date grouping- we group data into different non-overlapping class where the individual characteristic being generalize and fall into certain class. In these case, we cannot extract the raw data from the grouping data.

Frequency Distribution
We have qualitative and quantitative variable, For quantitative variable, the class is an interval of value. 

For example observation 1,2,3 will fall into class 0-5 , from the class itself we don't know about the raw data 1,2,3, the class is an interval it mans that the data can be 1.1,1.2 (continuous). Thus, the data will become continuous data after grouping regardless what type of numerical data it is.


But, that is a problem which is there is a gap between each class. For example, 0-5 and 6-10 due to non-overlapping property of class we cannot determine where the value between 5 and 6 fall into. Thus we need to define class boundary. A class boundary is a value shared by two consecutive classes.

To define a class boundary , we need to define class limit because class boundary is a midpoint between the upper limit of a class and the lower limit of the next class after it.

After we have class limit we can define class width which is the difference between the upper boundary and the lower boundary of a class gives the class width.

Given that the number of data points , how do we determine the number of class.
Sturge formula:
$$\begin{align}
\ k&=1+\log_{2} n \\
&=1+\frac{\log_{10}n}{\log_{10}2} \\
&=1+ 3.3 \log n
\end{align}
$$
where k=number of class, n=number of data points

After that, we can define class width with the range and k.
