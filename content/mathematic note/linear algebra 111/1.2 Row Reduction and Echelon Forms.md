
> [!question]
> TWO FUNDAMENTAL QUESTIONS ABOUT A LINEAR SYSTEM
> 
1.Is the system consistent; that is, does at least one solution exist ?
2.If a solution exists, is it the only one; that is, is the solution unique?

Definition a rectangular matrix is in echelon form if it has the following three properties:

1) All nonzero row are above any row of all zeros
2) The leading entry of a row is in a column right next to the leading entry of the row above it.
3) All entries under leading entry are zeros

![[Pasted image 20260402201955.png]]

If a matrix in echelon form satisfies the following additional conditions, then it is in reduced echelon form(or reduced row echelon form):

4) The leading entry in each nonzero row is 1.
5) Each leading 1 is the only nonzero entry in its column. 

Why?
From reduced echelon form, we can know the solution set straight away.

The second property of being reduced echelon form is actually the backward of elimination. (It is similar to back substitution but different way) 

> [!note] Theorem 1
> Each matrix is row equivalent to one and only one reduced echelon matrix.

Because reduced echelon is actually another way to write the solution set. Since the solution set is unique, thus we have only one reduced echelon form for any matrix.
Or we can say it is the simplest form.

### Pivot Positions

The pivot positions is the location corresponds to the leading entry 1 in reduced echelon form. A pivot column is a column of $A$ that contains a pivot position.

A pivot, is a nonzero number in a pivot position that issued as needed to create zeros via row operations.

### Solutions of Linear Systems

Suppose a matrix in reduced echelon form. The variable that in pivot position is called basic variable. The other variable is called a free variable. For example, 

$$
\begin{bmatrix} 
1 & 0 & -5 & 1 \\
0 & 1 & 1 & 4 \\
0 & 0 & 0 & 0
\end{bmatrix} 
$$
The $x_{1},x_{2}$ are basic variables while $x_{3}$ is free variable because the third column don't have pivot.  (Column is corresponding to variable of a system)

The solution set can be described explicitly by solving the reduced system of equations for the basic variables in terms of the free variables.

$$
\begin{cases}
x_{1}=1+5x_{3} \\
x_{2}=4-x_{3} \\
x_{3} \text{ is free}
\end{cases}
$$
Each different choice of $x_{3}$ determines a (different) solution of the system, and every solution of the system is determined by a choice of $x_{3}$.

> [!info]
It is called parametric description 
In mathematics, a **parametric description** (or parametric equation) is a way of defining a relationship where groups of variables are expressed in terms of one or more independent variables, called **parameters**.

> [!note] Theorem 2 (Existence and Uniqueness)
> A linear system is consistent if and only if the rightmost column of the augmented matrix is not a pivot column—that is, if and only if an echelon form of the augmented matrix has no row of the form
> $$\begin{bmatrix}0 & \dots & 0 & b\end{bmatrix}$$
>
> If a linear system is consistent, there exist 2 cases, 
> 1) there exists free variable (infinitely many solution) (Not all column have pivot)
> 2) no free variable exists
